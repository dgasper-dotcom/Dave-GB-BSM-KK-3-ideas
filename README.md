# Dave GB BSM KK 3 Ideas

This repository collects three paper-trading research projects:

- `Topstep Paper Trading`
- `Kalshi Already Happened + APY Paper Trading`
- `Pre-Announcement M and A Paper Trading`

Each folder contains the source code, setup notes, and lightweight artifacts for its project. Runtime caches, virtual environments, logs, raw data dumps, compressed transfer bundles, and local secrets were intentionally left out.

The local `all_keys.txt` file is ignored by Git and is not uploaded to GitHub.
